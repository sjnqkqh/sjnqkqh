소프트웨어가 만드는 **실질적인 임팩트**에 집중합니다.

현장의 비즈니스 문제를 기술로 직접 풀어 매출 성장이나 업무의 극단적인 효율화를 만드는 **FDE(Forward Deployed Engineer)**, 그리고 다양한 분야의 도메인 전문가들이 프로그래밍을 배워 자신의 전문성 위에서 양질의 소프트웨어를 직접 만들 수 있도록 돕는 **교육**에 깊은 관심을 두고 있습니다.

---

### 생각하고 일하는 방식

- **인터페이스와 보편적인 프로그래밍 룰**  
  전체 시스템의 흐름과 인터페이스 구조에 집중합니다. 자바를 베이스로 최근에는 파이썬을 주로 활용하고 있으며, 클린 코드처럼 언어를 타지 않는 보편적인 프로그래밍 원칙과 설계 방향성을 중요하게 여깁니다.

- **문제 정의와 사고 훈련**  
  "우리가 진짜 풀어야 할 도메인 문제가 무엇인가?"를 정의하는 논리적 사고방식을 중요하게 생각합니다. AI 시대일수록 스스로 생각을 구조화하고 논리적 빈틈을 찾아내는 훈련이 필요하다고 믿습니다.

- **배움과 공유**  
  오픈소스 라이브러리([line/kotlin-jdsl](https://github.com/line/kotlin-jdsl))에 기여하고, 학습과 현업에서 얻은 인사이트를 블로그와 유튜브에 꾸준히 기록합니다.
