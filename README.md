현장의 비즈니스 문제를 풀어 매출 성장이나 업무 효율화를 만들어내는 **FDE**, 그리고 각 도메인 전문가들이 프로그래밍의 보편적인 규칙을 배워 직접 좋은 소프트웨어를 만들 수 있도록 돕는 **양질의 소프트웨어 구축 교육**에 관심이 많습니다.

---

### 생각하고 일하는 방식

- **구현보단 인터페이스, 코딩보단 프로그래밍**  
  클린 코드처럼 언어를 타지 않는 보편적인 프로그래밍 원칙과 설계 방향성을 중심으로 전체 시스템의 흐름과 인터페이스 구조에 집중합니다.
  앞으로 프로그래밍 교육이 지향해야할 방식은 정밀한 엔지니어링과 보편화된 프로그래밍 두 가지 갈래로 나뉠 것이며, 저는 언어에 국한되지 않는 프로그래밍룰을 통해 모두가 각자 필요한 소프트웨어를 설계하고 만들어 낼 수 있는 세상을 지향합니다. 

- **문제 정의와 사고 훈련**  
  **"우리가 진짜 풀어야 할 문제가 무엇인가?"** 를 정의하는 논리적 사고방식을 중요하게 생각합니다. AI 시대일수록 스스로 생각을 구조화하고 논리적 빈틈을 찾아내는 훈련이 필요하다고 믿습니다.
  결국 프로그래밍은 논리와 문학의 1대1 결합입니다. 내가 필요로 하는 프로그램, 웹 페이지가 어떻게 나와야 하는지, 그리고 그것이 **왜** 필요한지 지속적으로 고민하고 사유하는 과정이 최상의 임팩트를 만들어 낸다고 생각합니다. 

- **배움과 공유**  
  오픈소스 라이브러리([line/kotlin-jdsl](https://github.com/line/kotlin-jdsl))에 기여하고, 학습과 현업에서 얻은 인사이트를 블로그와 유튜브에 꾸준히 기록합니다.
